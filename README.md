# CardioCare Exam Trainer

A single-file quiz game to get exam-ready on the **CardioCare Quest** scoping review
(playful health technology for hypertension management with and for Navajo/Indigenous
people who have disabilities).

Open `index.html` in any browser — no build, no server, no dependencies.

## Modes
- **Mixed Exam** — a shuffled 22-question gauntlet across everything
- **Big Picture** — the must-knows: the gap, novelty claim, search funnel, RQs, wording
- **Author Arena** — match each paper to the researcher who led it (with name hooks)
- **Findings & Numbers** — pick the real result (mmHg, %, n)
- **RQ Sort** — slot each paper into RQ1 / RQ2 / RQ3 (or closest neighbour)
- **Flashcards** — browse & flip: authors, hooks, takeaways, findings

Covers 32 core papers + 35 exam essentials. Progress (XP, level, best streak) saves
in the browser. Keyboard: 1–4 answer, Enter next, Space flip.

Built from the core-papers cheat sheet for Pavan Gorintla's PhD comprehensive exam.
